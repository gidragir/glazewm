# Итоги Итерации 3: Плавные микро-анимации сдвига холста и бэклог миникарты

В рамках третьей итерации была реализована легковесная пошаговая интерполяция панорамирования холста (микро-анимация) для устранения эффекта резкого визуального «телепортирования» при навигации по бесконечному холсту.

## Ключевые изменения

### 1. Пошаговая интерполяция сдвига холста (`wm`)
* В файле `platform_sync.rs` реализована функция `animate_pan_workspace`.
* При изменении `offset_x` (дельта > 20px) смещение выполняется не мгновенным прыжком, а через серию из 3–8 быстрых шагов с использованием функции сглаживания (*Ease-out Quadratic*):
  $$\text{progress}(t) = 1 - (1 - t)^2$$
* На каждом шаге позиции окон обновляются пакетом через `apply_window_positions` (`DeferWindowPos` с флагами `SWP_NOSIZE | SWP_NOACTIVATE | SWP_NOZORDER`), что минимизирует нагрузку на DWM.
* Логика подключена к:
  - Автоматическому панорамированию при смене фокуса (`auto_pan_viewport` в `platform_sync.rs` и `handle_window_focused.rs`).
  - Ручным командам сдвига `PanViewportLeft` и `PanViewportRight` в `wm.rs`.

### 2. Конфигурация анимаций (`wm-common`)
* В `GeneralConfig` добавлены поля:
  - `animation_enabled: bool` (по умолчанию `true`).
  - `animation_duration_ms: u32` (по умолчанию `90` мс).
* В `sample-config.yaml` добавлены соответствующие параметры с описанием.

### 3. Бэклог Zebar Minimap
* Создан документ `backlog_zebar_minimap.md` с описанием IPC-модели и алгоритма отрисовки виджета миникарты для статус-бара Zebar.
